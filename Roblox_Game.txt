CURRENT GAME LOOP
-----------------
The current map is an open home area with no perimeter walls. Each player claims
one of four plots, spawns beside a free Starter Cabin, and starts with one random
being assigned to work. Roll more original generated beings with coins. Rarity
affects income. Assign/unassign beings through the roster panel; each being also
appears as a generated collectible figure on a stand at the front of the plot.
Build and upgrade behind the stands using coins, wood, stone, and essence.

The co-op combat route and ordinary resource drops are future work. The DEV menu
is Studio-only and grants test materials for trying construction.

WHAT IS IMPLEMENTED
-------------------
- Rojo mapping for shared modules, server scripts, and client scripts.
- Open base map: central plaza/checkpoint, paths, four personal 8x8-cell plots,
  plot signs, and a free cabin on each claimed plot.
- Random being rolls: generated names, titles, ability, Common/Uncommon/Rare/Epic
  rarity, and per-being income. Maximum roster size is eight.
- Visible generated figures on stands at each player's plot; labels show name,
  rarity, and Working/Reserve status.
- Assigned beings produce passive coins. Roll price increases by 15 coins per
  owned being beyond the starter.
- Gather wood, stone, and essence from eight respawning resource nodes around
  the home area (F). Future mobs can add resource drops in the overworld.
- Building placement, upgrades, demolition, material costs, and server validation.
- Studio-only Build Pack: 5,000 coins, 500 wood, 500 stone, and 100 essence.
- Saving/loading coins, materials, beings, learned abilities, and buildings,
  including migration from the previous fixed-character saves.
- Sprint button and Left Ctrl; Shift remains dash. Combat controls remain, but
  there are no enemies in the current base-focused map.

RUNNING IN ROBLOX STUDIO
-----------------------
In PowerShell:
  cd C:\Games\AnimeRoguelikeDemo
  & 'C:\Games\rojo.exe' serve default.project.json

Keep the Rojo terminal open, connect the Studio plugin to 127.0.0.1:34872, and
press Play. The map appears at runtime. The DEV button only appears during Studio
play and only the server can apply its fixed grant pack.

If Rojo says the port is in use, another Rojo server is already listening;
connect Studio to that server or stop it before starting another. Double-clicking
rojo.exe may open a process, but the port conflict means a listener already owns
the address.

CONTROLS
--------
- Sprint: on-screen button or Left Ctrl.
- Roster: BASE / ROSTER button or B.
- Building: BASE button or V; click/tap to place, X cancels.
- Combat (currently without enemies): click/right-click attacks, Shift dash,
  C movement, Q/E learned abilities, R ultimate.
