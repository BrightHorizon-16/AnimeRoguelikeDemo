CURRENT GAME LOOP
-----------------
The current map is an open home area with no perimeter walls. Each player claims
one of four plots, spawns beside a free Starter Cabin, and starts with one random
creature assigned to work. Roll more original generated creatures with coins.
Rarity affects income. Assign/unassign creatures through the roster panel; each
creature appears as a modeled display on a stand at the front of the plot.
Build and upgrade behind the stands using coins, wood, stone, and essence.

The co-op combat route and ordinary resource drops are future work. The DEV menu
is Studio-only and grants test materials for trying construction.

WHAT IS IMPLEMENTED
-------------------
- Rojo mapping for shared modules, server scripts, and client scripts.
- Open base map: central plaza/checkpoint, paths, four personal 8x8-cell plots,
  plot signs, and a free cabin on each claimed plot.
- Creature rolls: original toy-like Slug, Pup, Moth, Toad, Jelly, Golem,
  Alpaca, and Mimic forms with generated names and abilities. Rarity tiers:
  Common, Uncommon, Rare, Epic, Legendary, Mythic. Maximum roster size is eight.
- Distinct procedural 3D creature models on plot stands; labels show name,
  rarity, Working/Reserve status, and income.
- Assigned creatures produce passive coins; higher rarity means higher income.
  Roll odds: Common 55%, Uncommon 28%, Rare 12%, Epic 4%, Legendary 0.9%,
  Mythic 0.1%. Roll price increases by 15 coins per extra creature.
- Gather wood, stone, and essence from eight respawning resource nodes around
  the home area (E). Future mobs can add resource drops in the overworld.
- Building placement, upgrades, demolition, material costs, and server validation.
  A full-size hologram shows the building shape, green/red validity, and a
  specific placement reason. Preview raycasts only target the player's plot.
- The runtime clears stale Studio Workspace scenery/terrain, untracked sibling
  server scripts, and StarterPack tools because those old place objects are not
  mapped by this Rojo project.
- Studio-only Build Pack: 5,000 coins, 500 wood, 500 stone, and 100 essence.
- Saving/loading coins, materials, beings, learned abilities, and buildings,
  including migration from the previous fixed-character saves.
- Hold-Shift sprint, E gather/select/place controls, Q dash, and clear builder
  access. Combat controls remain, but
  there are no enemies in the current base-focused map.

RUNNING IN ROBLOX STUDIO
-----------------------
In PowerShell:
  cd C:\Games\AnimeRoguelikeDemo
  & 'C:\Games\rojo.exe' serve default.project.json --port 34873

Keep the Rojo terminal open, connect the Studio plugin to 127.0.0.1:34873, and
press Play. The map appears at runtime. The DEV button only appears during Studio
play and only the server can apply its fixed grant pack.

Port 34872 was unavailable on this machine, so this project uses 34873. If that
port is busy, check for another Rojo server or choose a free port and use the
same address in both the Rojo command and Studio plugin.

CONTROLS
--------
- Movement: Roblox defaults (WASD and Space); hold Left Shift to sprint.
- Gather: E near a resource node.
- Roster: BEINGS button or N.
- Building: BUILD BASE button or B (V alias); E or click/tap selects/places,
  X cancels. The hologram shows the full structure and why a spot is invalid.
- A plain-text control list at the bottom left can be clicked to hide; click
  CONTROLS [+] to reopen it. The redundant MOVE action button was removed.
- Combat (currently without enemies): click/right-click attacks, Q dash,
  1/2 learned abilities, R ultimate.
