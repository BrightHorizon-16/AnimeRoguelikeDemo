# Project status - Generated Beings co-op prototype

Status date: 2026-10-13. Rojo-mapped Roblox prototype. Run `rojo serve`, connect the Studio plugin, press Play. The map is generated by the server at runtime, so the edit-mode viewport is empty before Play.

## Implemented
- Rojo mapping, placeholder beings (Kairo, Vexa, Mori, Nyx, Aru), shared Wildling enemies with pursuit and melee.
- Light/heavy attack, dash, movement leap, two learned ability slots, ultimate.
- Rewards: 12 coins and 1 shard to the last hitter. Recruitment for 50 coins (owned beings excluded). Workers earn 5 coins per 10 seconds.
- Absorb a reserve being to permanently learn its ability (the being is consumed).
- Knockout: back to base checkpoint, locked in base for 60 seconds.
- HUD, roster panel, controls, notifications.
- 2026-10-13 (Claude): floor glitches fixed and walled base built in `src/server/WorldBuilder.lua`. See CHANGELOG.md. Not yet tested in Studio.

## Files
- default.project.json - Rojo mapping
- src/shared/Config.lua - character catalog, economy and knockout settings
- src/server/Main.server.lua - enemies, combat, roster, economy, knockout
- src/server/WorldBuilder.lua - runtime map: floors, base, gate, rails, wilds
- src/client/Main.client.lua - HUD, roster controls, input, action buttons
- README.md, CHANGELOG.md, PROJECT_STATUS.md
