CURRENT STATUS
--------------
The project is a Rojo-mapped Roblox prototype. Connect Rojo, then press Play to
run it. The map is generated by the server script at runtime, so the edit-mode
viewport is empty before Play.

The user reported two visual issues on 2026-10-13: floor glitches, and a base
that was only a simple blockout. Both were addressed on 2026-10-15 by Claude
(see CHANGE LOG). The base builder was also built. None of the 2026-10-15 work
has been run in Roblox Studio yet; it was verified by syntax checks and by running
the real server scripts against a mocked Roblox environment (66 checks passed).
The first Studio run is the next step. The client UI (src/client/BuildMode.client.lua)
has only been syntax-checked.

WHAT HAS BEEN IMPLEMENTED
-------------------------
- Rojo project mapping in default.project.json.
- Original placeholder beings: Kairo, Vexa, Mori, Nyx, and Aru.
- Runtime-generated map: walled home island (plaza, Guild Hall with roster desk,
  five character stations, Recruitment Shrine, Absorption Altar, Expedition Gate),
  path, wilds, decorative crystals, and the Builder Grounds terrace. [Claude rebuilt
  the map on 2026-10-15; the original blockout was by Codex.]
- Floor fixes: no overlapping same-height floor faces, all enemy spawns and
  crystals over real floor, invisible rails along the path, wilds, and terrace,
  and a floor self-check that prints to the Output window on Play.
- Runtime-spawned shared Wildling enemies with basic pursuit and melee damage.
- Light attack, heavy attack, dash, movement leap, two learned ability slots,
  and an ultimate.
- Enemy defeat rewards: 12 coins and 1 shard for the last hitter (+ Bounty Board bonus).
- Character roster with one starting base worker and one reserve character.
- Random recruitment for 50 coins, with owned characters excluded from future
  recruit options.
- Assigned characters generate 5 coins per 10 seconds per worker. Base gives
  2 worker slots (enforced); Barracks add more.
- Reserve characters can be absorbed to permanently learn their ability; the
  character is consumed.
- Knockout sends the player back to the base checkpoint and locks them inside
  the base area for 60 seconds (Infirmary shortens it, minimum 10 seconds).
- BASE BUILDER: each player claims one of 4 plots in the Builder Grounds (behind
  the Guild Hall) and builds on a 6x6 grid with a placement preview (V key or BUILD
  button). Eight buildings: Crystal Mine, Barracks, Forge, Infirmary, Bounty Board,
  plus Lantern, Garden Tree, Hero Statue. Levels 1-3 with visible model upgrades,
  real effects (income, worker slots, damage, lock reduction, kill coins), sell for
  50% of coins spent. Server validates every request.
- Saving: coins, shards, roster, learned abilities, and buildings via DataStore.
  Never saves after a failed load. Needs a published place and Studio Access to
  API Services to work in Studio.
- HUD, roster management panel (shows workers used/slots), build panel, controls,
  currency display, and notifications.
- README with Rojo setup, controls, base builder, saving notes, and demo limits.
